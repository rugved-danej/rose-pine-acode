<h2 style="color: #c4a7e7; border-bottom: 2px solid #26233a; padding-bottom: 8px;">🌟 What's Included?</h2>

<p>This plugin brings the beautiful and highly acclaimed <strong style="color: #eb6f92;">Rosé Pine</strong> ecosystem directly to Acode! Every single element has been precisely mapped using the official palette to guarantee pixel-perfect accuracy.</p>

<p>Unlike other themes, this plugin is completely modular and gives you <strong>three different components</strong> that you can mix and match:</p>

<ul style="line-height: 1.8;">
  <li><strong style="color: #f6c177;">App UI Theme:</strong> Transforms the file manager, settings menus, popups, toolbars, and scrollbars into a gorgeous dark aesthetic.</li>
  <li><strong style="color: #9ccfd8;">Editor Theme:</strong> A fully custom-built CodeMirror 6 syntax highlight engine with exquisite color mappings for functions, tags, strings, and search-highlighting.</li>
  <li><strong style="color: #31748f;">Terminal Theme:</strong> Fully synchronizes Acode's xterm.js terminal with Rosé Pine ANSI color specifications.</li>
</ul>

<h2 style="color: #c4a7e7; border-bottom: 2px solid #26233a; padding-bottom: 8px;">🛠️ How to Use</h2>

<p>Because we believe in complete freedom, this plugin <strong>automatically syncs your Editor and Terminal themes the very first time you select the App theme</strong>! But you still retain complete control:</p>

<ul style="line-height: 1.8;">
  <li><strong>To theme the App UI:</strong> Go to <code style="color: #f6c177; background: #26233a; padding: 2px 6px; border-radius: 4px;">Settings -> App Theme</code> and select your favorite Rosé Pine flavor.</li>
  <li><strong>To theme the Editor:</strong> Go to <code style="color: #9ccfd8; background: #26233a; padding: 2px 6px; border-radius: 4px;">Settings -> Editor -> Theme</code>.</li>
  <li><strong>To theme the Terminal:</strong> Go to <code style="color: #31748f; background: #26233a; padding: 2px 6px; border-radius: 4px;">Settings -> Terminal -> Theme</code>.</li>
</ul>
